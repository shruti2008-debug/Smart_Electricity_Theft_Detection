# dashboard/

This folder is reserved for the **React Web Dashboard** of Smart Electricity Theft Detection.

## Purpose

The dashboard will serve as the primary interface for operators and administrators to remotely monitor energy consumption, view real-time sensor data, and manage theft alerts.

## Planned Features

- Real-time energy consumption charts (voltage, current, power, kWh)
- Theft alert feed with timestamps and severity levels
- Device status panel (ESP32 online/offline, relay state)
- Historical data browsing and filtering
- User authentication via Firebase Auth
- Remote relay control (supply cut/restore)

## Planned Stack

- **Framework:** React (with Vite)
- **UI Library:** TailwindCSS / Material UI
- **Charts:** Recharts or Chart.js
- **Backend:** Firebase Realtime Database / Firestore
- **Auth:** Firebase Authentication
